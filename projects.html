Startup Thailand League 2025 · Year 2

  3. จัดทำ Prototype
  4. Pitching แผนงาน

Tools used

CanvaPowerPointAI-Driven ToolsFigma

Outcome

E-COMMERCE · SYSTEM DESIGN● ● ●
E-commerce · System DesignShowcase 2026

Vietnamese Fashion Order Platform

แพลตฟอร์มสั่งซื้อเสื้อผ้าเวียดนามครบวงจร · Course project · Year 3

เสื้อผ้าแฟชั่นจากเวียดนามได้รับความนิยมมากในกลุ่มผู้บริโภคชาวไทย แต่การสั่งซื้อยังติดปัญหา ต้องติดต่อร้านค้าทีละร้านผ่านแอปแชท ค่าจัดส่งข้ามประเทศไม่โปร่งใส และไม่มีระบบติดตามพัสดุ แพลตฟอร์มนี้จึงรวมสินค้าจากหลายร้านในเวียดนามไว้ที่เดียว แสดงราคาและค่าจัดส่งข้ามประเทศอย่างชัดเจน พร้อมระบบติดตามสถานะคำสั่งซื้อที่เชื่อถือได้

My contribution

จัดทำโครงงานรายวิชานี้โดย มนสิชา เล็กล้วน และจัดทำโปสเตอร์นำเสนอระบบสำหรับนิทรรศการ

Process

  1. วิเคราะห์ปัญหาของผู้ซื้อ
  2. เขียนข้อกำหนดซอฟต์แวร์ (SRS)
  3. ออกแบบ User Workflow และระบบหลังบ้าน
  4. ออกแบบหน้าจอ (UI Mockup)

Key features

ค้นหาและกรองสินค้าคำนวณค่าจัดส่งตามน้ำหนักและปลายทางชำระเงินด้วย PromptPayติดตามสถานะคำสั่งซื้อAdmin Dashboard และส่งออก Excel/CSV

Outcome

ได้จัดแสดงผลงานในนิทรรศการ EAU Academic & Innovation Showcase 2026

E-COMMERCE · FRONT-END● ● ●
E-commerce · Front-endLive demo

Mello Shop

Extra project · UX/UI + Front-end

โปรเจกต์ระบบอีคอมเมิร์ซ/แพลตฟอร์ม Mello มุ่งเน้นการออกแบบประสบการณ์ใช้งาน (UX/UI) และระบบหน้าบ้าน (Front-end) เพื่อตอบโจทย์พฤติกรรมผู้บริโภคยุคดิจิทัล

My contribution

ออกแบบโครงสร้างหน้าจอ (UI Design) วิเคราะห์และออกแบบระบบ (System Flow) และพัฒนาส่วนการใช้งานจริง

Process

  1. ศึกษาความต้องการผู้ใช้ (User Research)
  2. ออกแบบ Wireframe & Prototype (Figma)
  3. พัฒนาและทดสอบระบบ

Tools used

FigmaHTMLCSSJavaScriptAI-Driven Tools

Outcome

ได้ระบบต้นแบบ (Prototype) ที่ใช้งานได้จริง มีการจัดวางเลย์เอาต์ที่ใช้งานง่าย สอดคล้องกับหลัก UX/UI และสามารถนำไปต่อยอดใช้งานได้จริง
